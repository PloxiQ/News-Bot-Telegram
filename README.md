## 🇷🇺 Русский

**PloxiQ News** — это умный Telegram-бот, который автоматически собирает, фильтрует и публикует свежие новости из мира видеоигр и искусственного интеллекта (нейросетей) прямо в ваш канал.

### ✨ Возможности:
- 📡 **Сбор новостей:** Работает с RSS-лентами популярных игровых порталов и AI-ресурсов.
- 🧠 **Умная обработка:** (Опционально) Может переписывать новости через нейросеть, убирая "воду" и делая текст уникальным.
- 🛡️ **Анти-дубликат:** Бот запоминает опубликованное и не спамит одинаковыми новостями.
- 🖼️ **Медиа:** Автоматически прикрепляет картинки к постам (если они есть в источнике).

### 🚀 Как запустить:
1. Установите **Python** (версия 3.9 или выше).
2. Скачайте файлы проекта и установите зависимости командой:
   `pip install -r requirements.txt`
3. Создайте бота через [@BotFather](https://t.me/BotFather) и получите **Токен**.
4. Добавьте бота в ваш Telegram-канал и сделайте его администратором.
5. Вставьте ваш Токен и ID канала в файл с настройками (обычно это `.env` или `config.py`).
6. Запустите бота командой:
   `python bot.py`

### ⚠️ Важно:
Чтобы бот работал круглосуточно, его нужно запустить на компьютере (который не будет выключаться) или на сервере (VPS).

## 🇬🇧 English

**PloxiQ News** is a smart Telegram bot that automatically collects, filters, and publishes the latest news from the world of video games and artificial intelligence (AI) directly to your channel.

### ✨ Features:
- 📡 **News Collection:** Works with RSS feeds from popular gaming portals and AI resources.
- 🧠 **Smart Processing:** (Optional) Can rewrite news using AI, removing fluff and making the text unique.
- 🛡️ **Anti-duplicate:** The bot remembers what has been published and won't spam identical news.
- 🖼️ **Media:** Automatically attaches images to posts (if available in the source).

### 🚀 How to run:
1. Install **Python** (version 3.9 or higher).
2. Download the project files and install dependencies using:
   `pip install -r requirements.txt`
3. Create a bot via [@BotFather](https://t.me/BotFather) and get your **Token**.
4. Add the bot to your Telegram channel and make it an administrator.
5. Insert your Token and Channel ID into the config file (usually `.env` or `config.py`).
6. Run the bot using:
   `python bot.py`

### ⚠️ Important:
For the bot to run 24/7, you need to host it on a computer (that won't be turned off) or a server (VPS).
